# Project 1 第一幕：聊天室版本

2026 年 10 月 31 日修订。家铭明确希望第一幕呈现供陌生人相互交流的聊天室。本版采用会话栏、聊天气泡、常驻文字输入框和发送按钮。原来的房间插画素材保留为参考，没有继续放在玩家界面。

## 先看画面

默认页面是带有明确“Interface preview”标记的示例聊天。你可以输入并发送一条预览消息、点击 End chat 查看结束状态、点击 Find someone to talk to 查看等待状态。单独发布的界面预览不会把你连接给真实陌生人。

## 在两台电脑间测试

在完整项目的 act-1 文件夹中运行：

```powershell
npm ci
npm run demo
```

服务器电脑打开 http://localhost:3000。第二台电脑在同一网络打开 http://服务器IPv4地址:3000。两端都点 Find someone to talk to，服务器会把正在等待的两人配到同一会话；也可以在 Have a room code? 中输入相同房间名。

配对后可以自由输入文字。Enter 发送，Shift+Enter 换行。End chat 离开当前会话；Start a new conversation 重新寻找对象。排练模式下，自由文字原样传输，快捷短句使用固定转换，不调用模型。

## 后续本地模型

安装并打开 Ollama，下载模型后，停止排练并改用正式启动命令：

```powershell
ollama pull llama3.2:1b
npm start
```

正式模式仍按 Boyd 的记录运行：原话 x → 本地 Ollama 抽象解释 → 输出 y → 对方界面。模型由运行 Node 的电脑调用，另一台浏览器不需要安装模型。真实模型的效果与速度要在该电脑确认。

## 目前的边界

本轮重点是聊天室画面。源码内也保留了本地双人联网、陌生人配对、消息转换与重连。已用两个浏览器窗口测试配对与自由文字双向传输；这不等于已在学校网络的两台实体电脑上测试。

公开给陌生人试玩的服务器部署属于后续步骤。现在的在线链接是供检查画面的私人预览；它没有真实访客配对服务。学校 Wi-Fi 可能隔离设备。第二台电脑通过普通局域网 HTTP 使用鼠标和文字；摄像头手势需要 localhost 或 HTTPS。
