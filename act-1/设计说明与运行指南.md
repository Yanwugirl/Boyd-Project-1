## 你看到的第一幕

首页是一个普通夜晚的房间。两人输入相同房间名进入。第一人坐在桌边，界面提示像是在和熟悉的人说话；第二人的形象覆盖机器人外壳，界面提示“你的陪伴者”。双方不是在和一个自动聊天角色轮流说话：**每条消息都必须来自另一名真人的实际操作。**

每次选择短句后，自己看到原话，对方看到被解释过的句子。你也可以点“write my own”输入自己的句子，便于按 Boyd 的输入例子测试。

模型的任务是解释输入，而不是替另一位玩家作答。例如，选择“我需要一点时间”时，本轮排练规则送出的是“在开门前，我需要一点空间”这一类隐喻。截图里的“抽象解释”没有指定唯一正确的风格；后续你和 Boyd 可以直接改 `prompts/abstract.txt`。

第一幕暂不展示原文和输出的对照。服务器保留 `{x, y, from, tone}`，留给第二幕揭示；这份数据没有公开接口。两个人的手或鼠标位置还会共同影响画面中的细线。双方各发送至少两句后，都选择“Leave this room together”，第一幕才结束。

## 先把它跑起来

### 先测试画面和联网

在 Windows 安装 Node.js 22 或以上版本。解压完整项目，在 VS Code 打开 **act-1** 文件夹，选择 Terminal → New Terminal，输入：

```powershell
npm ci
npm run demo
```

打开 **http://localhost:3000**，进入例如 `our-window` 的房间。展开底部 **Room & rehearsal details**，点击 **Open a second player**，就能在同一台电脑测试两端。页面顶端会明确写着排练模式。这里使用固定台词，**没有调用 Ollama**。

结束时回终端按 **Ctrl+C**。

### 再接上真正的本地 Ollama

安装并打开 [Ollama](https://ollama.com/download)。在终端下载一个小模型：

```powershell
ollama pull llama3.2:1b
```

模型页标注的下载大小约为 1.3 GB，下载时间与网络有关。回到项目终端运行：

```powershell
npm start
```

重新打开网页。底部详情应该显示 **local model ready**。若没有，先看 Ollama 是否在运行，再点 **Check again**。如果出现下载模型提示，模型名必须与 `ollama list` 中的名字一致。

这份完整包没有预装你电脑上的 Ollama 或模型；当前已验证的是服务端适配与错误处理，真实生成质量需要你电脑上的模型运行后确认。固定排练台词和真实模型生成的措辞不会完全相同。

### 两台电脑怎样连接

只有一台电脑需要运行 Node 和 Ollama。两台电脑连接同一个允许设备互访的网络。在服务器电脑运行 `ipconfig`，找 IPv4 地址。另一台电脑打开：

```text
http://服务器电脑的IPv4地址:3000/?room=our-window
```

学校公共 Wi-Fi 有时隔离设备；可以用个人路由器或手机热点。Windows 防火墙如果询问，允许 Node 在私人网络通信。两边需要使用相同房间名。

**摄像头限制：**浏览器一般只在 `localhost` 或 HTTPS 网址允许摄像头。另一台电脑访问普通 `http://局域网IP` 时，可以先用鼠标测试；正式两人手势演示需要 HTTPS。不要为此关闭浏览器安全设置。Ollama 只由 Node 访问，无须把 11434 端口暴露给另一台电脑。

GitHub 可以存源码，但 GitHub Pages 不能持续运行这份 Node 服务器。Render 的 `localhost` 指 Render 自己，也不能自动连接你电脑的 Ollama。本轮交付的是本地运行版本。

## 如何用手选择

点 **Use my hand**，首次要联网下载 ml5 手部模型并允许摄像头。用食指指尖控制圆形光标，在短句上停留 1.5 秒后发送。发送后把手移开，再选择下一句。手离开画面时会暂停，页面会反馈状态。可用鼠标选相同短句；打字是可选的测试输入。

摄像头画面只留在自己的浏览器里，不进入游戏画面，也不传给另一位玩家或 Ollama。联网发送的是选定文本和归一化位置。

## 后两幕怎样保持一致

请保留 **完整 `public/assets` 文件夹、`public/scene.js` 和 `tools/build-assets.py`**。独立素材包也附有这些文件。

- 房间、角色、外壳、桌子、椅子、手机、台灯、杯子、植物、门共十组 SVG。
- 颜色、比例、布局和随机种子写在 `design-tokens.json`。
- SVG 与 p5 读取的 `vector-assets.json` 来自同一份坐标，保证是同一套素材。
- 人物与外壳使用完全相同的坐标空间，第三幕只需不再绘制外壳。
- `ASSET_MANIFEST.json` 记录文件指纹，便于核对版本。

SVG 可以放入 Photoshop，也可在 Illustrator 编辑。完整游戏是 HTML/CSS/JavaScript + Node.js，不是 PSD；之前制作的 PSD 情绪板继续作为参考。

## 向 Boyd 怎样解释参考代码

`SOURCES.md` 包含具体网址、参考了什么、用在哪里、做了什么修改。优先看这三个：

1. [p5 Shape Primitives](https://p5js.org/examples/Shapes-And-Color-Shape-Primitives/)：房间和人物由基本图形搭出来。
2. [p5 Linear Interpolation](https://p5js.org/examples/Calculating-Values-Interpolate/)：让两人的动作、灯光和细线缓慢变化。
3. [p5 / ml5 Speak With Your Hands](https://p5js.org/tutorials/speak-with-your-hands/)：识别指尖位置，进一步改成停留选择句子。

这是学习其方法后组合、重写的项目代码，不是从 p5 网站下载了一个现成的完整游戏。联网房间与 Ollama 流程参考各自官方文档，链接同样保存在来源表里。

**英文口头说明：**

I used p5's shape primitives to build an ordinary domestic room and a robot shell that can be removed later. The hand tutorial gives us a fingertip position, which we use to choose a sentence. Following our diagram, the server stores the real player's input as x, sends it to local Ollama for an abstract interpretation, stores the result as y, and sends y to the other player. We keep x and y separate for the reveal in Act II. The model mediates the connection; both people still supply the actual words.
