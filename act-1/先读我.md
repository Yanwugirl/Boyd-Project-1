# Act 1 完整测试版：先读我

这份是可以实际运行的本地版本，包含玩家一、玩家二、左右双窗测试、Node.js 服务器、Socket.IO、Ollama 接口和测试记录页。不是之前只有示例聊天的在线预览。当前版本暂作测试，不覆盖“备份1”。

## 最快开始

1. 在 Windows 安装 Node.js 24 LTS。
2. 解压整个文件夹，双击 **START_ACT1.cmd**。首次会安装依赖，完成后自动打开启动页。如果浏览器没自动打开，访问 **http://localhost:3000**。运行期间保持终端窗口打开。
3. 先在 Message mode 选择 **Connection test · send unchanged**，点击 **Create test session**。
4. 你会看到 **Open Player 1** 和 **Open Player 2** 两个独立入口。一个人测试可直接点 **Open both players side by side**，在左右两端分别输入、互相回复。每个房间的每个玩家只打开一次。

玩家一侧栏写着 PLAYER 1，聊天对象提示为 Someone；玩家二侧栏写着 PLAYER 2，聊天对象提示为 Companion。两端连接同一个房间，消息会从一端实时送到另一端。

## 接入真正的 Ollama

1. 安装并打开 **Ollama**：https://ollama.com/download/windows 。
2. 双击 **SETUP_OLLAMA.cmd** 下载默认模型 `qwen2.5:1.5b`。如果你已经装过别的模型，启动页也能选它；不必重复下载同名模型。
3. 启动页点击 **Refresh**，确认 Ollama 和模型都就绪。
4. 点 **Test Ollama**，先看输入原话转换成什么句子。这是真正的模型请求，不是固定回复。
5. Message mode 选择 **Ollama · interpret each message**，选择模型，再创建一个新房间。打开玩家一与玩家二，测试真实的 `x → Ollama → y → 对方`。

模型的工作是解释或改写消息，另一位玩家仍需亲自回复。一个人也可以在双窗页扮演两人，测试完整的往返。

## 第一幕怎么走完

- 开始：两人进入自己的聊天界面，各自看到不同的对话身份提示。
- 交流：输入文字，Enter 或按钮发送；Shift+Enter 换行。快捷短句也可以发送。自己看到原话，对方看到处理后的句子；发送中会提示等待，成功后显示 Delivered。
- 核对：启动页下方记录每条消息的原文 x、送达内容 y、使用的模式与耗时。这个核对区只在测试启动页出现，玩家页面不会提前看到反转。
- 结束：双方各发送至少两条消息后，点击各自页面上的 **Continue together**。两人都确认后，第一幕结束。第二、三幕尚不在这份 Act 1 中。

## 两台实体电脑

只在第一台电脑运行 Node 和 Ollama。两台连同一个可互访的网络。启动页下方展开 **Use two different computers**，复制相应的玩家链接给另一台电脑。第二台电脑打开链接即可，不需要安装 Node 或 Ollama。

如果自动列不出地址，在第一台电脑终端运行 `ipconfig`，使用其 IPv4 地址替换链接中的 localhost，例如 `http://192.168.x.x:3000/player2.html?room=实际房间号`。保持房间号完整。

学校 Wi-Fi 可能隔离设备，可换手机热点或私人网络。Windows 防火墙如询问，允许 Node 在私人网络通信。通过普通局域网 HTTP 可以使用文字和鼠标；摄像头手势需要 localhost 或 HTTPS。不要把 Ollama 的 11434 端口暴露给别人。

切换到另一组设备或另一种测试方式时，创建新房间最方便。

## 这份包包含什么

- `public/index.html`：完整测试启动页。
- `/player1.html?room=…` 与 `/player2.html?room=…`：Node 服务器提供的两个独立玩家入口。
- `public/chat.html`、`public/app.js`：两端共用的界面与交互代码，依据玩家身份显示不同信息。
- `public/dual.html`：两份独立连接并排展示，方便单人测试。
- `server.cjs`：房间、身份、消息传输、重连、第一幕结束与受保护的测试记录。
- `lib/interpreter.cjs`、`prompts/abstract.txt`：Ollama 接口与可修改的消息转换指令。
- `tools/doctor.cjs`：可用 `npm run doctor` 检查本机连接。
- `TEST_RESULTS_REAL_OLLAMA.json`：本次实际模型与双客户端测试记录（若生成成功）。
- `VERIFICATION.md`：已测试范围及仍需在你电脑确认的事项。
- `public/assets` 与相关绘图文件：之前素材原样保留，供后续幕使用。

默认只在内存保存对话，重启服务器会清空房间和消息。不要通过双击 HTML 或 Live Server 来进行联网测试；请用 START_ACT1.cmd 启动 Node。

原来的在线链接仍是旧界面预览，这次请使用新包的本地启动页测试。待家铭测试满意后，再将这份完整版本列为新的“备份1”。
