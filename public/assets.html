One visual language.
Three acts.

The room, person, removable robot shell and objects below belong to the same asset set. The game draws these vector primitives with p5.js. These SVG exports use the exact same coordinates and colours.

Asset version: act1-2026-10-31-v1. Keep these files when building Acts II and III.

Code references

p5.js · Shape Primitives ↗ — build a room and people from simple shapes.
p5.js · Linear Interpolation ↗ — make presence and light change gradually.
p5.js · noise() ↗ — quiet motion without visual jitter.
p5.js / ml5.js · Speak With Your Hands ↗ — detect a fingertip and use it as input.
Ollama · Chat API ↗ — translate a player's x into a delivered y.
Socket.IO · Tutorial ↗ — exchange messages between two browsers.

For classroom discussion

“We use p5's shape primitives to keep the visual world simple and reusable. Hand tracking lets the body choose a line. Socket.IO carries the choice, and a local Ollama model interprets it before it reaches the other player. The model is translating one person's words; it is not replacing the second player.”
