# Act 2 The Filter Room 设计与试玩说明

2026 年 11 月 12 日更新。替换旧版“倾听圆环 + 符号门”玩法。

## 设计出发点

第一幕里，界面在两人之间改写了每一句话。第二幕让两人发现：他们一直在和对方说话，而那个界面还在房间里。它仍然会改写打出来的字，也会把人的手势往“安慰人的回答”那边拉。要找回对方真正想说的话，两人只能靠手（或鼠标）交流，并且要从“动作不完美”里认出对方。

这一幕同时回应 Project 1 brief 的三项硬性要求：

- **Socket.io 实时传输**：两人的光点位置和游戏状态都经由我们自己的 Node.js 服务器实时转发。
- **生成式视觉系统**：两人移动的轨迹会在地板上留下慢慢褪色的线，每次游玩织出的图案都不同，取决于在场的人和他们的动作。
- **ml5.js 图像处理**：ml5 handPose 从摄像头提取手的 21 个关键点。只用食指尖：它就是玩家的“光”，带一小段拖尾传给对方。摄像头画面不显示、不传输，只传食指尖的坐标。

ml5 的识别抖动没有被藏起来，反而成了玩法：对方的光会像真人的手一样晃动，界面的光却永远平稳。这对应 brief 里“通过使用来理解 ML 工具的局限”。

## 全程流程

| 段落 | 两人做什么 | 推进条件 |
|---|---|---|
| 揭示 | 对照第一幕的原话与送达文字，各自点 Step into the room | 两人都确认 |
| 第 1–3 句 | 写这句话的人用光指出原话，收到的人去同一句汇合 | 两人的光同时停在真正的原话上 |
| 还原 | 看到原话、送达版本、界面想说的话三者对照 | 两人都点 Next message |
| 合成钥匙 | 两人的光一起进入中央圆圈 | 一起停留约 1.6 秒 |
| 门口 | 两人分别选择 Continue together | 双方同意，进入第三幕 |

每一轮用的都是这个房间第一幕里真实发过的消息，优先选被改写过的句子，并且写信人轮流交替（先玩家二，再玩家一，再玩家二）。所以两个人都会当一次“写信人”和“收信人”。

## 一轮怎么玩

房间里有三张卡片，各是一句话：

1. 写信人当时真正写的原话；
2. 实际送到对方屏幕上的改写版本；
3. 界面更想说的一句安慰话（例如 “I'm always here for you.”）。

**写信人**能读到三张卡片，自己的原话有虚线框和 YOUR WORDS 标记。只要手（或鼠标）在动，界面就会把写信人的光往“安慰话”那张卡片拉；保持静止约 1 秒，光才会落回手真正指的位置。光停在一张卡片上约 0.9 秒后会“定住”，卡片顶部出现一个实心圆点。

**收信人**只能读到有光停留的卡片。房间里有两个同色的光：一个是写信人（会晃、带拖尾），另一个是界面（平稳地绕着安慰话转圈）。收信人要把自己的光停在写信人定住的那张卡片上约 1.3 秒。

- 两人在原话上汇合：还原成功。
- 收信人跟了界面的光：界面替对方回答，屏幕显示那句安慰话“不是他们写的”，重来。
- 写信人定在了别的卡片上：显示“这不是他们写的”，重来。

失败两次后，面板会给提示。每一轮开始或失败后，光要先移动一下才会被计算，避免一进来就误触。

## 显卡加速（重要）

手势识别必须在浏览器里开启显卡加速。Edge：`edge://settings/system` →“在可用时使用图形加速”→ 重启浏览器。检查方法：打开 `http://localhost:3000/hand-test.html`，点 Start camera，Graphics backend 应该是 webgl 或 webgpu，不能是 cpu；举手时手上会出现绿点和黄点。

## 操作方式

- **手势**：点 Use my hand。食指尖就是你的光；在按钮上停留 1.5 秒可以按下按钮。需要 localhost 或 HTTPS 地址，以及能加载 ml5 的网络。
- **鼠标 / 触屏**：在房间里移动鼠标或手指，光会跟着走。
- **键盘**：方向键移动光。

没有摄像头的玩家也能完整参与。

## 可以调的参数

全部在 `public/acts/act2-layout.json`，改完刷新页面、重启服务器即可：

- `pull`：界面拉光的力度（0.45 = 拉到 45% 的距离）。
- `settleMs`：保持静止多久后光完全落回原位。
- `stillThreshold`：多小的晃动算“静止”。如果用手势时一直定不住，把它调大一点（例如 0.06）。
- `pinMs` / `meetMs` / `joinMs`：定住、汇合、合钥各需要停留的时间。
- `comfortLines`：界面爱说的安慰话。

## 改了哪些文件

| 文件 | 作用 |
|---|---|
| `lib/act2.cjs` | 服务器端规则：选消息、拉光、定住、汇合、还原、合钥。整套判定都在服务器上，两边看到的结果一致。 |
| `public/acts/act2.mjs` | 两个玩家看到的画面和右侧面板（p5.js 绘制房间、光点、地板上的线）。 |
| `public/acts/act2-filter.css` | 新面板元素的样式，玩家一保持 XP/AIM 风格，玩家二保持绿色风格。 |
| `public/acts/act2-layout.json` | 卡片位置和所有可调参数。 |
| `public/gesture.js` | 手势识别：每秒约 15 次，先把摄像头画面画到画布上再识别（Edge 的 WebGPU 直接读视频会得到空帧）；没有显卡加速时会提示并改用鼠标。 |
| `public/acts/manifest.json` | 第二幕底部提示文字。 |
| `server.cjs` | 只改一行：创建第二幕时把第一幕的消息传进去。 |
| `test/act2-rules.test.cjs`、`test/act2.test.cjs` | 新玩法的测试。 |

## 试玩时请观察

收信人能不能不经解释就分清两种光；写信人有没有发现“静止”才能抵抗拉力；一轮大概要多久；两个人是否都觉得自己被需要；还原画面里“原话 / 送达 / 界面想说的”三者对照，是否让主题更清楚。
